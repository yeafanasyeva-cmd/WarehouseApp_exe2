## Требования
- Windows 10/11
- PostgreSQL 14+

## Установка и запуск
1. Установите PostgreSQL с официального сайта
2. Создайте базу данных в pgAdmin4 (например, `WarehouseApp`)
3. Выполните SQL-скрипт (файл `backup_warehouseapp.sql` в папке с программой)
4. Запустите `WarehouseApp.exe`

## Настройте подключение при первом запуске:
   - Введите хост, порт, имя бд, логин и пароль PostgreSQL
   - Нажмите "Проверить подключение"
   - Нажмите "Подключиться"
